รายการ Prompt ที่ใช้
ช่วยออกแบบโปรเจกต์วิเคราะห์ข้อมูลหุ้นแบบโดยใช้ Apache Airflow, PySpark และ FastAPI Dashboardให้หน่อยสิ่งที่ต้องทำคือ
1.วางโครงสร้างโฟลเดอร์โปรเจกต์สำหรับ pipeline หุ้น โดยแยกเป็น dags, jobs, web, scripts, tests และ output
2.เขียน PySpark job สำหรับอ่านไฟล์ CSV หุ้นจาก StockHistory แล้วแปลงเป็น Parquet
3.เขียนขั้นตอนทำความสะอาดข้อมูลหุ้น เช่น ลบข้อมูลที่ไม่ถูกต้อง เติมค่าราคาที่หายไป ลบแถวที่ไม่มีการซื้อขาย และจัดรูปแบบวันที่
4.เขียน PySpark สำหรับคำนวณตัวชี้วัดทางเทคนิคและสร้าง logic สำหรับเลือกพอร์ตหุ้นรายเดือน
5.เขียน Airflow DAG สำหรับรัน pipeline หลัก ตั้งแต่แปลง CSV เป็น Parquet, clean data, calculate indicators, select portfolio และ export portfolio
6.ตั้งค่า Docker Compose สำหรับรัน Airflow, Postgres และ FastAPI Dashboard ภายในโปรเจกต์เดียวกัน

เพิ่ม Airflow DAG สำหรับ Growth Portfolio Pipeline และ Dashboard Refresh Pipeline
แก้ปัญหา Airflow DAG import error และตรวจสอบว่า DAG โหลดได้ถูกต้อง
สร้าง FastAPI backend สำหรับอ่านไฟล์ JSON/CSV ที่ export จาก pipeline แล้วส่งข้อมูลให้ dashboard
สร้างหน้า Market Dashboard สำหรับแสดงภาพรวมตลาดหุ้น เช่น market breadth, heatmap, risk-return scatter, movers และตารางหุ้น
เพิ่ม filter ใน dashboard เช่น เลือกปี, ticker, signal, RSI zone, price band และสถานะว่าอยู่ใน portfolio หรือ growth watchlist
สร้างหน้า Investment Insights เพื่อแสดงหุ้นที่น่าสนใจ พร้อม label เช่น Worth Watching, Stable และ Caution
เพิ่มหน้า Architecture สำหรับอธิบายโครงสร้าง pipeline เพื่อใช้ในการนำเสนอโปรเจกต์
ช่วยปรับ UI ของ dashboard ให้ดูเป็นระบบ อ่านง่าย และเหมาะสำหรับงานนำเสนอ
ช่วยสร้าง JSON snapshot สำหรับ dashboard เช่น market_dashboard.json และ investment_insights.json
ช่วยเขียน test เพื่อตรวจสอบโครงสร้างโปรเจกต์และ payload ของ dashboard
ช่วยเขียน script สำหรับรัน pipeline ทั้งหมดในเครื่อง local ด้วย PowerShell
ช่วยสร้าง README อธิบายวิธีติดตั้ง วิธีรัน pipeline วิธีเปิด dashboard และคำอธิบาย output ของโปรเจกต์
ช่วยเพิ่ม .gitignore เพื่อไม่ให้ commit ไฟล์ dataset ขนาดใหญ่, output, virtual environment และไฟล์ generated artifacts
ช่วยตรวจสอบและปรับ performance ของ Spark job ให้รองรับข้อมูลหุ้นจำนวนมาก
ช่วยตรวจสอบสถานะ Docker containers, Airflow health endpoint และสถานะ DAG run
ช่วยเขียนเอกสาร handoff สำหรับบันทึกสถานะ Airflow, DAG ที่กำลังรัน และคำสั่งที่ใช้ตรวจสอบต่อ
ช่วยตรวจสอบความถูกต้องของ dashboard หลังปรับแก้ และสร้าง screenshot สำหรับใช้ประกอบการนำเสนอ

3. final picks ต้องผ่านทั้ง growth ranking และสัญญาณล่าสุด

5. เพิ่มคะแนนคัดเลือก/Decision Score ที่รวม signal score, growth rank และ risk warning
6. ถ้าบางตัวโตแรงแต่ยังไม่ผ่านสัญญาณ ให้แยกไว้ อย่าปนกับตัวแนะนำ
7. ปรับข้อความบนหน้าเว็บให้คนดูเข้าใจง่ายว่า final 20 ใช้คะแนนคัดเลือก ส่วน radar 140 ใช้คะแนนสัญญาณ
